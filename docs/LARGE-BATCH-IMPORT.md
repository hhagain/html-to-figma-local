# v0.9.0 大批次导入

本版去掉固定 200 页 / 200 文件阈值。支持单个 HTML 中的更多页面、多个 HTML/JSON 文件、含更多页面的 h2f-bundle、状态清单、预览和桌面传输。页面按顺序导入为同一个 Figma Page 下的独立 Frame。

## 保留的资源预算

- 单页：6000 节点，24 MB 图片，300 个图片资源及现有内容/深度/尺寸校验。
- 整批：120,000 个捕获节点；共享图片去重后 64 MB、2000 个资源。
- 输入文件总量及桌面传输请求：128 MB；含截图备份仍需满足独立的预览体积校验。
- 动态清单：每状态最多 80 步、整批最多 8000 个操作。没有固定状态数上限。

因此“不限制页数”不等同于无限内存或无限图层。很多简单页面可一次导入，少量非常复杂的页面也可能先达到节点或资源预算。超出时会明确报错，应分区或分文件处理。

## 自动发现的范围

默认不按候选页数截断。API 可以显式设置正整数 maxPages 作为这一轮的任务预算，超过 200 的值也接受；不传或传 null 表示不设页数预算。

导航发现仍最多实际检查 30 页、约 60 秒；交互探索默认按 300 次尝试、3 分钟运行。目录扫描、深度、写请求限制也继续生效。结果会报告剩余候选和受限情况，这些任务预算不是导入页数限制。

## 升级

静态 HTML / JSON 导入需要新版 Figma 插件。网页、多状态和桌面直传请同时更新桌面助手，避免旧版后端仍按 200 拒绝。原有 v1 数据和配对保持兼容。

## 验证

新增 1000 页的资源去重和批次导入回归；真实浏览器解析 1000 页 HTML，通过编译插件和 Figma API 测试宿主逐页导入。另覆盖 250 个源文件、1000 页备份末页预览、1000 页传输和超过 200 页的本地发现。

测试宿主不等同于真实 Figma 客户端或任意电脑上的性能承诺；真实项目仍受页面复杂度、可用内存、Figma 和文件规模影响。
