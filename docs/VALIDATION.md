# v0.2.1 Auto Layout 修复验证

## 根因及修复

Figma 的 `layoutMode` 从 NONE 切换到 HORIZONTAL / VERTICAL 时，会立即重算框架尺寸与子层位置。旧实现随后设置 FIXED，但没有恢复原始尺寸，导致固定高度按钮缩成文字高度，整屏容器和居中弹窗失去原来的高度依据。

新增模拟 Figma 原生布局副作用的测试后，旧实现的五个场景全部失败；修复后全部通过。新版恢复容器宽高、固定子框架尺寸，随后核对直接子层几何。超过 1.5 px 差异或发生原生布局异常时，会撤销该容器的 Auto Layout 并恢复原状态。

## 用户提供的登录设计

输入：`01 · 华为账号快捷登录-export.html`。原文件保持不变。

根因：HTML 通过 Tailwind CDN 脚本生成宽高、定位、颜色和布局，旧版静态预览移除脚本后没有生成这些样式。修复前解析为约 `1436 × 11748` 的长页面，SVG 按默认尺寸排列，导致画布看起来主要剩下图标。

修复：离线编译 Tailwind 3 的静态类名与字面量配置，保留原有脚本禁用边界；去除内部 iframe 的默认边框；保留 `data-pencil-name`。
