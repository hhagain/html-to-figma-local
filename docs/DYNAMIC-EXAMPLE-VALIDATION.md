## 修复与验证要点

- 状态之间隔离本地存储，避免新增/筛选状态污染后续捕获。
- 等待明确的最终界面。SQL 状态等待 `SQL · Monaco Editor`，没有把加载占位当作完成。
- Monaco 内部存在 16,777,216 × 16,777,216 的虚拟容器；按祖先可见区域裁剪后保留可见编辑器文字。
- 零像素辅助 Canvas 不生成缺失图片占位；实际可见 Canvas 仍以位图表示。
- 原生 select 当前选中项、checkbox/radio 勾选状态作为静态文字和图形捕获。
- 状态任务支持进度、取消保留、单状态失败继续及覆盖报告；失败清单不会被算作成功。

## 静态产物边界

导入的 Figma 画面没有原页面的执行逻辑、接口、动画或数据连接。每个状态是独立静态 Frame，文字和常规图层可以继续编辑。Canvas、复杂滤镜、CSS 伪元素和浏览器原生弹出菜单仍有转换限制；诊断信息保留在数据与报告中。
