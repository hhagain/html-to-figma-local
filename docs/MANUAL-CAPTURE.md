# 手动操作原 HTML 并标记（v0.15.0）

适合设计师自己决定哪些状态作为页面，其余状态只保留可复用组件与图标的工作流。原 HTML 在助手内置的独立浏览器中持续运行，工作台将你的点击、输入和滚动传给这个真实页面。右侧实时操作区支持交互。

## 使用步骤

1. 从菜单栏或系统托盘退出旧助手，打开 v0.15.0；Figma 插件也更新到同版本。
2. 在助手中打开捕获工作台，进入 **网页链接 → 多状态捕获 → 手动操作原网页并标记**。
3. 输入网址或本地 HTML 地址。支持 `file:///…/index.html#/route`、`/Users/…/index.html`、`Users/…/index.html`、`C:\…\index.html` 以及路径中的 `%20`。设置浏览器宽度与捕获区域。
4. 按需要选择 **整理其余已浏览状态为组件和图标**，以及 **按勾选顺序 / 智能排版**。
5. 点击 **打开原网页，开始标记**。在右侧直接点击、填写、展开、切换页面与滚动。它使用独立登录和存储，不继承系统浏览器的登录会话。
6. 到达需要导出的状态时，填写可选名称，选择 **当前页面 / 完整长页**，点击 **标记当前状态**。新标记默认勾选；继续操作原网页，逐个添加。
7. 在清单中勾选需要的整页。名称前显示勾选序号；可以改名、删除、逐条切换捕获范围。取消后重新勾选的标记追加到最后。
8. 点击 **生成设计稿**，检查页面、组件、图标预览。可下载 `.h2f.json`、发送到 Figma 插件，或选择已连接的目标后直接导入 Figma。
9. 需要调整时点击 **继续操作原网页**，修改标记后重新生成；结束时点击 **结束操作** 释放浏览器。

在 Figma 插件选择手动模式后，按钮会打开助手工作台，带上入口地址和宽度。标记操作完成后可从工作台直接导入已连接的 Figma 文件。

## 每条标记的捕获范围

| 范围 | 输出 |
| --- | --- |
| 当前页面 | 标记时的浏览器视口及滚动位置，保留当前可见布局 |
| 完整长页 | 标记时已加载的主页面连续内容，生成一个可编辑长 Frame |

标记时保存当时两个范围的可编辑快照，后续操作原网页不会覆盖它们。清单中切换范围使用已保存的数据，无需重放交互。完整长页无法满足尺寸或资源预算时会提示原因，不会将未成功保存的长页当作可选项。

长页只展开主滚动区。卡片、局部列表、弹窗仍保留自身视口与裁切；关闭的折叠内容保持关闭。捕获后恢复实时网页的样式和滚动位置。虚拟列表、无限滚动和懒加载内容以标记时已加载的 DOM 为限。

## 组件和图标开关

- **开启**：用户停留、操作后的稳定状态会被记录。未勾选为整页的已记录状态参与组件与图标整理；相同结构的文案、金额等数据差异合并，同类结构保留代表组件，展开、填写等结构状态保留为组件状态，图标按图形去重。
- **关闭**：只导出勾选的整页，不附加组件或图标库，并暂停后续自动状态记录。

关闭前已经记录的素材仍保留在本次会话中，重新开启后可继续使用。关闭期间没有记录的状态需要再操作到该状态。快速掠过、尚未稳定或没有浏览过的交互不保证被记录；任何需要完整保留的状态都应手动标记。

组件和图标来自已加载 DOM 的可见元素，不会读取和遍历整份源代码里的所有隐藏分支，也不会穷举未操作过的页面。

## 导出排版

| 选项 | 行为 |
| --- | --- |
| 按勾选顺序 | 整页按勾选先后生成普通网格，随后排列组件库、图标库。重新勾选会改变顺序 |
| 智能排版 | 按模块、页面层级与所属功能组织整页，组件和图标分别集中排版 |

“智能排版”控制画布上多页的组织方式。“智能 Auto Layout”控制单页内部的布局，两者独立。排版选择随 JSON、桌面传输和插件导入保留。

## 实时操作

- 鼠标点击、拖动、滚轮作用于原网页。
- 键盘输入支持中文与粘贴；网页聚焦后可使用全选、方向键和删除键。
- `Ctrl / ⌘ + 滚轮` 缩放操作区，亦可选择 100% 或适应宽度。
- `Esc` 发送给网页后释放工作台的键盘焦点，再次点击网页可继续。
- HTML 原生下拉选项和浏览器对话框在操作区上方显示对应控件。

原 HTML 的脚本与页面状态运行在隔离浏览器上下文，接触不到工作台连接码或本机其他浏览器会话。跨站跳转、额外窗口和文件下载不属于当前手动页面会话。

## 保存与限制

原 HTML 文件保持不变。会话保留于助手运行内存，结束会话、退出助手或重启会清除尚未导出的标记。生成后请下载 JSON 保存，或直接导入 Figma。重新打开同一连接的工作台并点击打开，可以接回仍在运行的手动会话。

沿用单页和整批图层、图片、尺寸预算；不设置固定页数上限。手动会话暂存预算为 256 MB，达到时会明确提示，请先导出已有标记并分批继续。Figma 输出为可编辑静态页面和组件，交互事件与数据逻辑不会随图层运行。
