# 安装与多页导入指南

## 已经安装过开发插件

如果原插件指向本项目目录中的 `manifest.json`，关闭并重新运行 **HTML to Figma · Local** 即可。底部显示 **v0.10.0** 表示加载了新版。

## 使用 ZIP 安装

1. 完整解压 `html-to-figma-local-0.10.0.zip` 到固定目录。
2. 在 Figma 桌面端选择 **Plugins → Development → Import plugin from manifest…**。
3. 选择解压目录中的 `manifest.json`。
4. 从 **Plugins → Development → HTML to Figma · Local** 运行。
5. 保留 `manifest.json` 和 `dist/` 的相对位置。加载已构建插件不需要安装 Node 依赖。

## 导入多页 HTML

1. 在“文件”入口选择 HTML。也可以一次选择多个 HTML。
2. 保持“自动拆分多页面”开启。
3. 普通桌面页面使用合适的浏览器宽度；手机设计也应以原 HTML 的布局视口为准。固定尺寸 Pencil 导出会保留每个设计页自身的宽高。
4. 捕获区域通常保留 `body`。自动识别不符合预期时，填写实际页面选择器，例如 `.page`、`.screen`。
5. 点击“解析并预览”。确认页面总数、每页名称和尺寸；可以全选、清空或逐页勾选。
6. 点击“导入到 Figma”。插件按页创建独立 Frame，已完成页在列表中显示完成状态。
7. 如有单页失败，查看对应原因；其他页面继续。取消会保留已完成页；插件仍打开时可以继续未完成页。

## 这次登录页文件

`01 · 华为账号快捷登录-export.html` 依赖 Tailwind。新版会自动在本地编译样式，无需手工添加 CSS，也不需要连接 CDN。

- 开启自动拆分：识别为 4 页，每页 `390 × 844`。
- 要整张画布：关闭自动拆分，宽度填写 `1740`，捕获区域填写 `body > div`，得到 `1740 × 844`。
- 使用“视觉还原”作为首次导入模式；需要布局整理时再尝试“智能 Auto Layout”。

## 注意范围

- 页面导入为当前 Figma Page 中的独立 Frame，不会按导入页数创建左侧 Pages 条目。
- 不设固定页数上限；整批超过 120,000 个捕获节点、64 MB 共享图片或 128 MB 输入文件时，请通过选择器或分文件拆批。
- 进度状态只保留在当前插件会话；关闭插件后需要自行避开已完成页面，避免重复导入。
- React / Vue 等需要执行 JavaScript 的页面使用“网页链接”入口和本地捕获服务。文件入口支持静态 HTML 与 Tailwind 3 静态配置。
- 真实测试结果和更多限制见 `VALIDATION.md` 与根目录 `README.md`。


## 从 v0.2.0 更新：自动布局问题

如果旧版导入后出现按钮变矮、底部操作上移或弹窗贴到顶部，请使用 v0.2.1 从原 HTML 重新导入。已创建的旧图层不会自动调整。

新版保留符合条件的原生 Auto Layout，但会恢复原始宽高并检查子图层几何。无法保持布局的容器自动回退到视觉位置，在转换说明中提示。复杂布局和直接文字容器不强制转为 Auto Layout。


## 动态网页多个状态

选择“网页链接 → 多状态捕获”，加载状态清单并连接本地服务；完成后可按状态选择导入。详见 `DYNAMIC-STATES.md`。


## 不使用终端的网页捕获

安装并打开 macOS 捕获助手，在 Figma 插件的“网页链接”中点击“连接桌面助手”。核对配对码并确认一次，后续自动重连。见 `DESKTOP-ASSISTANT.md`。
