# 单张长页与智能排版开关（v0.11.0）

捕获工作台的“画布与布局”区域提供两个独立选项，默认都开启。

| 设置 | 开启 | 关闭 |
| --- | --- | --- |
| 单张长页 | 展开当前已加载的滚动内容，一个状态生成一个可编辑长 Frame | 使用现有视口捕获，滚动位置分别生成页面 |
| 智能排版 | 按模块、页面层级及功能状态生成分类分区 | 按捕获顺序使用普通网格排列 |

“智能排版”与“智能 Auto Layout”含义不同：前者决定多个页面如何排列；后者决定每个页面内部是否使用安全的自动布局。关闭智能排版后，原 HTML 已有的绝对定位画布仍保留其原坐标。

## 连续长页

长页通过临时展开捕获浏览器中的滚动容器生成完整 DOM 快照，并非将首尾两张截图拼在一起。当前已加载的中间内容也会包含在长 Frame 中，文字、矢量与常规图层继续可编辑。捕获后恢复临时样式及滚动位置，原 HTML 文件不会被修改。

同一状态仅滚动位置不同的重复请求会合并到同一个输出页；报告同时记录请求状态数、输出页面数和合并数。选择下半段单独捕获，也会从该状态的顶部生成完整长页。填写、筛选、弹窗等真实状态变化继续分开保留。滚动触发了新内容加载时，保留独立长页并提示内容变化，避免静默丢失新内容。

固定顶部和底部控件各保留一次。弹窗打开时优先展开弹窗自身的滚动区域，不展开背后的页面。

边界：

- 包含当前已加载的 DOM，虚拟列表和无限滚动不代表全部数据已经加载。
- 每页图层、字符、资源与尺寸预算仍生效；超过高度预算会明确报错，可以关闭单张长页后分段捕获。
- 特别长的页面可能只提供首屏预览并给出转换说明，图层数据按实际成功捕获范围生成。
- 展开后会按新的布局高度渲染，依赖视口或滚动位置的特效可能与逐屏浏览不同。

## 智能排版开关

可在捕获前或捕获后切换，不必为了改变排版重新捕获。关闭时保留分类元数据，再次开启可以恢复分组。设置随导出 JSON、备份和桌面直传传递，接收插件会遵守这批数据的选择。

工作台记住用户手动设置。首次加载的旧数据没有导入选项时沿用当前选择；旧版本行为默认保持智能排版开启。

## 使用步骤

1. 同时更新助手和 Figma 插件到 v0.11.0。
2. 在网页链接入口输入网址或本地 HTML，按需要设置“单张长页”。
3. 探索并勾选状态，开始捕获；检查报告中的合并数与输出页数。
4. 按需要开关“智能排版”，然后发送或导入 Figma。

旧版首尾截图缺少完整中间 DOM，需要从原 HTML 重新捕获才能生成连续长页。
