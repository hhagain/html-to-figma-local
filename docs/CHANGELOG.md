# 更新记录

## 0.2.0 — 2026-10-21

- 支持一个 HTML 中的 100–200 个页面与多 HTML 文件批量选择。
- 自动识别 Pencil 和常见页面标记；支持自定义页面选择器、勾选和分批导入。
- 每页独立 Frame；共享图片去重、字体/图片缓存、逐页进度和预算校验。
- 单页失败继续处理；取消时只清理当前页；同次插件会话中可继续未完成页。
- 修复 Tailwind CDN HTML 导入时失去样式的问题，使用离线 Tailwind 3.4.17 编译。
- 修复 Figma sandbox 中 randomUUID 不可用、完成通知未被处理和预览边框尺寸偏差。
- 保留 data-pencil-name 中文图层名称。
- 修复构建时 `$` 替换序列损坏内嵌脚本的问题。
- 真实 Figma 验证：四屏登录设计恢复完整；200 页压力样例完成 200 / 200、失败 0。

## 0.1.0

初始本地开发版：HTML 捕获、资源内嵌、Figma 图层生成、字体替代、基础样式、保守 Auto Layout、取消与回滚。
