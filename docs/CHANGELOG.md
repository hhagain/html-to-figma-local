# 更新记录

## 0.8.1 — 2026-10-26

- 修复 Windows 安装包和便携 ZIP 缺少 playwright / playwright-core，导致后台启动即退出的问题。
- 为运行依赖建立明确的资源复制项，构建后核对依赖实际位于包内，并生成逐文件校验清单。
- EXE 安装和 ZIP 解压验收改为仓库之外的独立目录，两种分发方式分别启动和捕获。
- 新增启动依赖预检查和脱敏启动日志，“助手”菜单可以显示日志位置。
- 提供仅补齐 Windows v0.8.0 运行依赖的小体积修复包。

## 0.8.0 — 2026-10-23

- 新增 Windows x64 桌面助手，交付 NSIS EXE 安装包与便携 ZIP，内置运行环境和浏览器。
- 支持托盘常驻、单实例、服务恢复、原生配对、稳定插件导出和保留已有插件 ID。
- 修复 Windows 盘符、本地 file URL、嵌套资源和状态重放路径；保持目录越界、隐藏文件、设备名与备用数据流限制。
- Windows 原生桥接限定本机主页面和待处理配对请求，捕获页面无法调用原生命令。
- 增加 Windows CI、安装后应用验收与安装包校验文件；Windows 预览使用 Ctrl + 滚轮。

## 0.7.0 — 2026-10-23

- 桌面选择已连接的 Figma 文件/页面后一键导入，插件自动执行；保留手动接收方式。新增目标心跳、上下文版本与写入前目标校验。
- 只传递勾选页和布局模式，支持导入进度、完成、部分失败和取消状态回传。
- 本地传输鉴权、单接收端认领、重复请求保护与临时数据过期；支持最多 200 页。
- 预览新增 10%–400% 缩放、100%、适应窗口、⌘/Ctrl + 滚轮及空格 + 左键拖拽，静态 HTML 与截图均支持。
- 支持带 JPEG 预览的本地捕获备份，升级时可恢复已有多页结果和截图。
- 实机恢复 148 页及全部预览，桌面一键导入所选 2 页成功、0 失败；100% 和适应窗口通过原生操作验证。组合缩放/拖拽手势已通过自动化测试，原生手势验证仍有限制。


## 0.6.0 — 交互探索与渐变修复

- 新增自动交互探索：详情、弹窗、表单示例与校验、选择与滚动状态，自动生成可重放清单。
- 探索结果明确列出候选边界、未处理操作、失败、重复与跳过项，并支持导出报告/清单。
- 捕获时验证探索状态摘要，拒绝把变化或不稳定的状态当作成功。
- 修复同类控件取样遗漏第四个导航，以及折叠区域中的输入被错误填写的问题。
- 修复线性渐变像素色标和缩放前尺寸换算，支持渐变文字并避免矩形背景色块；等比缩放字体同步转换。


## 0.5.1 — 2026-10-22

- 修复多状态捕获只有第一张截图可预览的问题，按成功页面保存独立截图。
- 桌面工作台增加上一页、下一页、页面选择、当前页标题和页面列表预览入口。
- 预览按需鉴权加载、最多缓存 3 页，快速切换取消旧请求，支持失败重试及过期提示。
- 预览存储于本机临时目录，随旧任务淘汰和服务退出清理；导出包不附带截图。


## 0.5.0 — 2026-10-22

- 新增自动发现页面：同源链接、导航标签及本地 HTML 目录扫描，最多 200 个候选页面。
- 多状态默认无需 JSON，先发现、再勾选、再捕获；支持进度、取消、全选、清空和重新发现，编辑地址后失效旧结果。
- 支持 `/Users/…` 和 `Users/…` 本地路径，以及编码空格、中文、查询参数、hash 路由与复制路径的引号。
- 保留高级状态清单入口，已有 JSON 和示例仍可使用。
- 独立发现任务与捕获任务互斥，使用相同配对鉴权；发现过程限制目录、同源导航、写请求与操作范围。


## 0.4.1 — 2026-10-22

- 桌面助手和插件支持 `file:///` 本地动态 HTML，正确解析编码路径、query 和 hash 路由。
- JS 模块、CSS、图片、字体、JSON 通过捕获浏览器内的临时地址读取，限定入口目录，阻止路径越界与符号链接逃逸。
- 单页、多状态、入口快照和来源记录共享本地文件处理；本地状态继续支持逐页失败与取消。
- 修复取消捕获时重复关闭浏览器上下文导致的完成时序竞态。
- 应用图标、菜单栏及助手首页使用用户提供的 H PNG。


## 0.4.0 — 2026-10-22

- 新增原生 macOS 捕获助手，内置独立 Node 和 Chromium；用户无需安装 Node 或执行 npm 命令。
- 新增助手首页、内置捕获工作台、菜单栏常驻、窗口重开、服务重启与退出清理。
- Figma 插件自动发现 3847–3851 的本机助手；首次配对需要核对六位码，凭据持久化后自动重连。

- 助手可导出稳定安装位置的开发插件，并保留已有 Figma 插件 ID。
- 交付 Apple Silicon / macOS 14+ 的 .app、DMG 与 ZIP；本地 ad-hoc 签名，未公证。
