# 无状态清单的动态 HTML：探索设置与继续探索（v0.12.0）

## 使用方式

1. 更新桌面助手和 Figma 插件到 v0.12.0。
2. 在“网页链接”输入网址或本地 HTML 路径，选择“多状态捕获”。
3. 页面来源保持“自动探索交互”，展开“探索设置”。
4. 首次使用可选“推荐”；复杂原型可选“深入”，或选“尽量遍历 · 无总上限”。
5. 点击“探索交互状态”。可随时停止，已记录状态与待探索队列会保留。
6. 查看停止原因和待探索数量，调整配置后点击“继续探索”。已有状态编号和勾选结果保留，新增状态默认勾选。
7. 勾选要捕获的状态，开始捕获并检查多页预览，再导入 Figma。

HTML 无需提供 JSON 清单。助手自动生成点击、填写、选择、等待与滚动步骤，“导出已选状态清单”可以保存和复用这些步骤。

## 预算与控件范围

| 配置 | 推荐 | 深入 | 无总上限 |
| --- | --- | --- | --- |
| 完整操作路径深度 | 4 层 | 10 层 | 不限 |
| 每轮尝试次数 | 300 | 3000 | 不限 |
| 每轮时长 | 3 分钟 | 30 分钟 | 不限 |
| 每轮新增状态数 | 不限 | 不限 | 不限 |
| 控件范围 | 同类控件取代表样本 | 遍历已识别的控件与选项 | 遍历已识别的控件与选项 |

每项均可单独修改，填 `0` 表示不限。时间、尝试次数和新增状态数按每轮重新计算；深度按从入口开始的完整路径计算。无总上限仍保留取消、单个动作和导航的超时保护。长路径的总回放时间随步骤增加，不再固定截断在 18 秒。

代表样本模式对同类控件、下拉选项和滚动区域取代表位置，每状态最多生成 45 个候选动作。遍历模式取消这些控件数量采样，允许在不同状态中重试同一入口，并保留状态去重。表单使用示例值，滚动使用代表位置；任意输入值、日期和业务数据组合仍无法穷举。

## 继续探索

停止时保存的是实际操作队列、已访问状态摘要、去重信息、失败路径和深度受限路径。“下载探索报告”只列出前 100 条待处理路径的摘要，内部队列不受该报告展示数量限制。

- 时长或尝试次数用完：继续后得到新一轮预算。
- 深度达到上限：提高深度或改为 `0` 后继续。深度不变时不会执行超出该深度的路径。
- 从代表样本切换到遍历控件：重新检查已记录状态，补充之前被采样省略的候选，不重复生成同一状态。
- 动作失败：保持“继续时重试失败动作”开启，重试尚未成功的路径。历史失败记录仍保留在报告中。
- 用户停止或时间耗尽时正在执行的动作：回到待处理队列，下轮重放，不计为普通失败。

进度由运行中的助手保存，仅当前连接可继续。入口、视口及捕获区域需要一致；改变这些条件请重新探索。助手保留最近 4 个探索会话，每个会话完成一轮后最多保留 24 小时；助手退出或工作台刷新后请重新探索。导出的状态清单只包含已发现状态，不能恢复未处理队列。修改原 HTML 后建议重新探索，防止旧路径与新内容混用。

## 报告与覆盖范围

报告区分累计尝试、不同状态、重复状态、失败、未处理动作、深度受限动作，以及受限控件、采样省略和重复路径。候选动作可能通向重复或失败状态，其数量不等于尚缺多少页。报告分别显示手动停止、时长、尝试次数、新增状态数、深度、队列处理完成等原因。

自动探索覆盖主导航、同源链接、详情、设置、编辑、展开、弹窗、示例填写、本地空白必填项校验、原生选项和代表滚动位置。从入口独立重放每条路径，不使用用户日常浏览器中的登录或本地存储。捕获时重新检查状态摘要，页面变化或重放失败会明确报错。

文件选择、设备权限、敏感账号字段、显式删除/授权/支付控件、已填写表单提交会跳过；HTTP 写请求、跨站导航、WebSocket 和 sendBeacon 会被阻止。需要真实登录、上传、权限、网络失败、悬停/长按、特定数据或时间条件的状态，可为原型补充直接进入的演示入口，或使用高级状态清单显式提供步骤。

“队列处理完成”表示当前可识别且允许执行的队列已处理，不是所有产品交互的完整覆盖。网站可能不断生成新数据、日期或状态，即使取消全部预算，也可能持续运行。捕获结果 `N/N` 仅表示所选状态的重放结果。

## 本地 API

```json
{
  "url": "http://127.0.0.1:8080/",
  "exploreInteractions": true,
  "maxDepth": 0,
  "maxActions": 0,
  "maxPages": 0,
  "timeoutMs": null,
  "sampling": "all",
  "retryFailures": true
}
```

向 `POST /api/discover` 发送请求，轮询任务并读取结果。结果中的 `session.id` 是不透明会话标识。继续时向同一接口发送相同入口、视口和选择器及 `resumeId: session.id`，并传入新的预算。会话绑定连接身份，不接收客户端提供的可执行检查点。每项预算可用 `0` / `null` 表示不限；有限值需要正整数，有限 `timeoutMs` 至少 1000 毫秒。

“仅发现导航页面”仍采用独立的快速导航扫描策略，不提供交互队列继续功能。
