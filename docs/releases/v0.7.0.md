# HTML to Figma · Local v0.7.0

发布于 2026-10-23，开发预览版。本次汇总 v0.2.0 之后的桌面助手、多状态捕获和导入改进。

## 下载与安装

- **HTML-to-Figma-Capture-0.7.0-mac-arm64.dmg**：推荐的桌面安装包，适用于 Apple Silicon（M 系列）和 macOS 14+。
- **HTML-to-Figma-Capture-0.7.0-mac-arm64.zip**：相同桌面应用的 ZIP 版本，完整解压后使用。
- **html-to-figma-local-0.7.0.zip**：配套 Figma 开发插件与项目文件。
- **SHA256SUMS.txt**：上述三个安装包的 SHA-256 校验值。

桌面助手已内置 Node.js 和捕获浏览器，无需 npm 或终端服务。安装并打开助手后，点击“显示 Figma 插件”，在 Figma 的 Plugins → Development → Import plugin from manifest 中加载 manifest.json；首次连接时核对配对码并在助手中允许连接。

## 这次更新

- **桌面一键导入 Figma**：捕获后勾选页面，选择已连接的 Figma 文件和页面，点击“直接导入 Figma”。目标插件保持运行即可自动接收、导入并回传进度与结果。
- **自动探索动态 HTML**：无需预先编写状态 JSON，探索导航、详情、弹窗、表单和代表性滚动状态，供用户勾选捕获；保留导航发现和高级状态清单。
- **100–200 页工作流**：每批最多 200 页；每页独立预览，支持翻页、选页、共享资源去重、逐页失败反馈与取消。
- **预览缩放和平移**：10%–400% 缩放、100%、适应窗口、Cmd/Ctrl + 滚轮、空格 + 左键拖拽。支持恢复带 JPEG 预览的本地捕获备份。
- **本地动态 HTML**：支持 file:///、/Users/…、Users/… 路径，以及编码空格、查询参数和 hash 路由。
- **还原与布局修复**：修复部分顶部线性渐变、渐变文字和缩放字体问题；Auto Layout 转换后检查尺寸与位置，发生偏移时恢复原布局。

## 验证结果

- 完整回归 82 项通过；最终传输保护相关 5 项再次通过。
- 真实 macOS 助手恢复了 148 页及 148 张预览；在独立 Figma 验收页面执行桌面一键导入，所选 2 页全部完成、0 失败，无需在插件内再次点击导入。
- 148 页、38,401 个捕获节点通过包内服务的完整数据往返校验；这项校验不代表真实 Figma 已导入全部 148 页。
- 100% 和适应窗口已完成原生窗口验证。Cmd/Ctrl + 滚轮、空格拖拽已通过自动化测试；原生组合手势尚未可靠验证。

## 当前边界

- 桌面包仅提供 Apple Silicon/macOS 14+；实际测试机为 macOS 15.5。
- 应用为 ad-hoc 签名，未经过 Apple Developer ID 公证。首次打开如被系统拦截，请使用 macOS 提供的“隐私与安全性”确认流程。
- Figma 插件仍通过开发插件方式加载，直接导入时需要在目标文件中保持运行。
- 自动探索受状态数、尝试次数、深度和时间预算限制，探索报告中的未处理项需人工检查，不能保证覆盖所有交互组合。
- 捕获浏览器使用独立会话，不继承日常浏览器的登录状态；复杂 CSS、字体和跨域资源仍可能存在还原差异。

安装和操作说明见仓库 README、docs/DESKTOP-ASSISTANT.md 和 docs/DIRECT-HANDOFF.md；详细验证范围见 docs/DESKTOP-VALIDATION.md。
