# HTML to Figma · Local v0.8.0 — Windows 桌面助手

发布于 2026-10-23，Windows x64 开发预览版。

## 下载

- `HTML-to-Figma-Capture-0.8.0-win-x64-Setup.exe`：安装向导，默认按当前用户安装，可选择安装目录。
- `HTML-to-Figma-Capture-0.8.0-win-x64.zip`：便携应用，完整解压后运行 `HTML to Figma Capture.exe`。
- `html-to-figma-local-0.8.0.zip`：配套 Figma 开发插件和项目文件。
- `SHA256SUMS-windows.txt`：Windows 安装包 SHA-256 校验值。

应用内置运行环境与捕获浏览器，无需安装 Node.js、npm 或另外启动终端服务。面向 Windows 11 x64；Windows ARM64 尚未提供。Mac 版 v0.7.0 可继续从原发布页下载，本次没有替换 Mac 安装包。

## 新增内容

- Windows 原生窗口、单实例、系统托盘常驻、服务重启和退出清理。
- 助手与 Figma 开发插件配对、自动重连、插件导出与保留已有插件 ID。
- 支持 `C:\…\index.html`、`file:///C:/…`、中文与空格路径，以及查询参数和 hash 路由。
- 自动探索交互、最多 200 页捕获、逐页预览和勾选后直接传给 Figma 插件。
- 预览支持 Ctrl + 滚轮缩放、空格 + 左键拖拽、100% 和适应窗口。
- 修复 Windows 短路径编码不同导致同一页面重复发现的问题。

## 使用

1. 安装并打开助手，等待“捕获引擎已就绪”。
2. 点击“显示 Figma 插件”，在 Windows Figma 桌面端通过 Plugins → Development → Import plugin from manifest 加载展示的 manifest.json。
3. 运行插件，连接助手，核对配对码并在助手首页允许连接。
4. 打开捕获工作台，输入网页或本地 HTML 地址；需要多个状态时使用“自动探索交互”，勾选并捕获。
5. 保持目标 Figma 文件中的插件运行，在助手中选择该文件/页面，点击“直接导入 Figma”。
6. 关闭窗口后服务保留在托盘；从托盘菜单选择“退出捕获助手”停止后台。

## 验证边界

Windows 构建与自动化安装验收由 GitHub Actions 的 Windows Server 2022 x64 环境执行。真实 Windows Figma 桌面文件、Windows 11 用户桌面和 SmartScreen 首次运行流程仍需要实际设备验证。传输测试使用自动接收端，真实导入代码由回归测试宿主验证。

应用为未进行代码签名的开发预览包，系统可能显示未知发布者。下载后可使用 PowerShell 的 `Get-FileHash` 核对 SHA-256。详细安装和构建方式见 `docs/WINDOWS-ASSISTANT.md`。
