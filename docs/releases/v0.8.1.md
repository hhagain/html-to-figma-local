# HTML to Figma · Local v0.8.1 — Windows 启动修复

2026-10-26，开发预览版。建议 Windows v0.8.0 用户升级。

## 修复内容

v0.8.0 Windows 分发包漏带 playwright 和 playwright-core，导致捕获服务启动时发生 ERR_MODULE_NOT_FOUND 并以退出码 1 结束。两项依赖改为明确复制项，构建后核对包内文件并生成 SHA-256 清单。

原验收目录位于构建仓库内，误用了仓库的父目录依赖。新版 EXE 安装、便携 ZIP 解压和运行验收均移到仓库之外，分别检查依赖完整性、启动与捕获。

新增启动依赖检查和日志入口：助手 → 显示启动诊断日志。仍为未签名的 Windows x64 开发预览版，应用内置运行环境和浏览器，无需 npm。

## 安装

- 下载 HTML-to-Figma-Capture-0.8.1-win-x64-Setup.exe，退出旧助手后安装更新。
- 或完整解压 HTML-to-Figma-Capture-0.8.1-win-x64.zip 后运行。
- 已有 v0.8.0 便携版也可以使用 H2F-Windows-0.8.0-Runtime-Repair.zip，只补齐缺失的捕获依赖。
- 配套 Figma 插件为 html-to-figma-local-0.8.1.zip，可从助手重新导出。

应用数据与既有配对保留。详细原因见 docs/WINDOWS-STARTUP-FIX.md，安装指南见 docs/WINDOWS-ASSISTANT.md。真实 Windows Figma 客户端文件联调仍需实际设备确认。
