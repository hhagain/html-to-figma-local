# HTML to Figma · Local v0.9.0 — 取消 200 页限制

2026-10-27，开发预览版。

- 不再因超过 200 页或 200 个文件拒绝导入，覆盖静态 HTML、多个文件、捕获 JSON、动态状态清单、预览和桌面直传。
- 保持逐页创建独立 Frame，支持取消并保留已完成的页面。
- 自动发现默认不设页数预算；仍按时间、操作、深度与扫描范围运行，API 可显式提供 maxPages。
- 保留每批 120,000 节点、共享图片 64 MB / 2000 个资源及 128 MB 输入/传输体积约束。去除页数限制不表示无限内存或无限图层。
- 已加入 1000 页解析与编译插件测试宿主导入、250 文件选择和第 1000 页预览验证。
- 助手连接区新增“下载桌面助手”链接。

静态文件导入更新插件即可；网页捕获、多状态与直传应同时更新助手。Windows 保留 v0.8.1 的依赖自包含修复；Windows x64 与 macOS Apple Silicon 分别使用对应安装包。

构建和自动化测试记录会在仓库中说明；真实 Figma 客户端的大项目性能还需结合页面复杂度和用户设备确认。Mac 为 ad-hoc 签名，Windows 未代码签名。
