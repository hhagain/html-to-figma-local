## 本次更新

- 在“网页链接 → 多状态捕获”新增 **手动操作原网页并标记**。自行点击、输入、填写、滚动原 HTML，再标记与勾选要导出的整页，无需状态清单 JSON。
- **页面名称可编辑**：标记时命名，之后可在标记清单中修改；修改后重新生成，名称用于预览、导出及 Figma Frame。
- **逐页捕获范围**：每条标记独立选择“当前页面 / 完整长页”。保存当时可编辑的页面快照，后续操作不覆盖标记，切换范围无需重放交互。
- **组件与图标独立开关**：可选择是否整理其余已记录状态。关闭后只导出勾选整页；开启后同类结构归并为代表组件，图标按图形去重。
- **两种导出排版**：按勾选顺序，或按页面与功能智能排版。取消后重新勾选的页面追加到最后。排版选择随 JSON、桌面传输和 Figma 导入保留。
- 原网页操作区支持中文输入、粘贴、滚动、拖动、原生下拉和对话框，默认适应窗口，支持 100% 与 Ctrl / ⌘ + 滚轮缩放。
- 修复滚动后当前视口快照的图层坐标偏移；长页仍保留局部列表、卡片、折叠区域和弹窗的裁切及内部滚动状态。

## 相比公开 v0.9.0 新增的能力

- 页面、功能、组件状态的分类排版，以及去重后的独立图标库。
- 页面入口和主导航优先探索，减少只有部分 Tab 被捕获的问题。
- 设计稿模式合并仅金额、文字等数据不同的整页，将局部差异整理为组件状态；同表单保留一个代表页面。
- 探索深度、每轮次数、时长和状态数可配置，支持停止后继续探索。
- 连续长页捕获、独立智能排版开关，以及 SVG 环形图虚线与路径长度修正。

## 更新步骤

1. 从 macOS 菜单栏或 Windows 系统托盘退出旧助手。
2. 使用同平台 v0.15.0 安装包更新；便携版需完整解压新版目录。
3. 在新版助手点击“显示 Figma 插件”，使用该目录中的 `manifest.json`；已加载原目录的插件需关闭后重新运行，确认底部显示 v0.15.0。
4. 保持目标 Figma 文件中的插件运行并连接助手。在工作台捕获、选择目标后，可直接导入 Figma。
5. 手动标记详见仓库 `docs/MANUAL-CAPTURE.md`；原有自动探索和状态清单继续可用。

- Windows 构建、安装版和便携版已运行验证，覆盖配对、捕获、插件导出、直传流程和手动标记选项。

- 手动模式只包含用户操作时已记录的状态，不会穷举未浏览的交互；虚拟列表与无限滚动以当时已加载内容为限。
