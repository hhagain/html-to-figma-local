# 在桌面助手直接导入 Figma（v0.7.0）

## 一键导入

1. 在目标 Figma 文件中打开 HTML to Figma · Local 插件并连接助手，选好要放置设计的页面。插件需要保持运行。
2. 在桌面助手捕获并勾选需要导入的页面。
3. 在“导入目标”中核对 Figma 文件和页面名称。多个插件窗口同时运行时可以选择目标。
4. 点击“直接导入 Figma（N 页）”。目标插件自动接收并生成图层，不需要切到 Figma 再点按钮，也不需要 JSON 文件中转。
5. 助手显示导入进度和完成数量。部分失败或取消时查看插件结果，已完成的页面保留。

Figma 目标在发送前、接收时、写入画布前都会核对。目标文件/页面变化、插件离线或忙碌时不会静默改投到其他文件。导入开始后批次绑定当时的目标页。

“发送到 Figma 插件”作为备用方式：先发送，稍后在插件中点击“接收并导入当前页面”。该方式不固定文件，需要在正确的插件窗口接收。

## 预览缩放与快捷操作

- `＋ / −`：分级放大、缩小，手动范围 10%–400%。
- `100%`：按截图实际尺寸显示。
- `适应窗口`：让完整预览适应当前可视区域。
- `⌘ + 滚轮`：围绕鼠标位置连续缩放；也兼容 Ctrl + 滚轮。
- `空格 + 鼠标左键拖拽`：平移放大后的预览，光标变成抓手。释放空格或鼠标即停止。
- 放大后仍可正常横向、纵向滚动；翻页保留缩放方式。
- 鼠标需位于预览区域。输入框中的空格保持正常输入，不触发拖拽。
- 静态 HTML 的 iframe 预览同样支持缩放，内部布局宽度不变。

缩放和平移不修改浏览器捕获宽度、导出数据或 Figma 节点尺寸。

## 保留与重复操作

- 助手需持续运行。手动发送的待接收结果暂存最多 30 分钟；退出助手会清除临时传输。
- 一批结果只允许指定或首次认领的一个插件窗口导入。
- 重复发送请求不会创建重复批次；已完成后再次点击“再次导入”属于新的导入操作。
- 插件接收后被关闭时，不会自动在另一文件续接。请检查已完成页面，再从助手重新发送，避免重复。
- 下载数据仍可用于长期保存。带 JPEG 预览数组的本地备份可恢复截图；传到 Figma 的 bundle 不含这些预览截图。
