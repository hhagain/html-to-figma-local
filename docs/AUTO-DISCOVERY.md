# 自动发现页面（v0.5.0）

从 v0.6.0 起，多状态默认使用“自动探索交互”，可发现详情、弹窗和表单状态，无需原 HTML 提供清单；详见 `INTERACTION-EXPLORATION.md`。本文的轻量模式现名为“仅发现导航页面”。

## 操作步骤

1. 打开 v0.5.0 桌面助手，点击“显示 Figma 插件”同步新版插件，再重新运行 Figma 开发插件。
2. 选择“网页链接”，捕获方式选“多状态捕获”。页面来源默认是“自动发现页面”。
3. 粘贴网址或本地 HTML 路径。
4. 点击底部“自动发现页面”。界面显示已找到和已检查的数量，可以取消。
5. 在发现结果中勾选需要的页面，可全选、清空或重新发现。
6. 点击“开始捕获（N 页）”。只有勾选的页面会被捕获。
7. 检查捕获结果和失败报告，再点击“导入到 Figma”。

更换地址、浏览器宽度或捕获区域会清除旧发现结果，需要重新发现，以免导入上一次页面的数据。未勾选任何页面时不能开始捕获。无法打开的页面会显示原因，修复资源或地址后可重新发现。

## 可直接粘贴的本地格式

```text
Users/yourname/Design%20Project/index.html
/Users/yourname/Design Project/index.html
file:///Users/yourname/Design%20Project/index.html
Users/yourname/Design%20Project/index.html#/dashboard
/Users/yourname/Design Project/index.html?mode=demo#/dashboard
```

`yourname` 应替换为实际用户名；HTML 文件必须存在。支持 Finder 复制路径带来的成对引号，路径里的中文、空格和百分号会正确编码。`Users/` 开头按 macOS `/Users/` 绝对路径处理，不依赖应用的当前目录。其他相对路径不作猜测。

## 自动发现范围

- 同站点、同源的可见页面链接，包括 hash 路由。
- 可见的导航标签、导航区域按钮；生成相应的点击步骤，捕获时独立重放。
- 本地入口所在目录及两层子目录中的 `.html` / `.htm` 文件；目录枚举最多检查 3000 个条目。
- 页面去重、失败提示、发现进度、取消及最多 200 页的候选列表。
- 初次发现最多实际打开 30 页，导航检查深度 2，总时长约 60 秒上限。超出检查范围的候选保留，可勾选并在捕获时验证；达到 200 页上限的其余页面需要换入口分批处理。

普通页内锚点、隐藏链接、下载项、跨站页面、隐藏文件和符号链接不作为本地目录发现目标。导航时跳过有明显删除、提交、支付等含义的控件，并限制网络写请求。自动发现执行页面本身脚本，始终在独立的临时浏览器会话里运行；不修改源文件，不继承现有浏览器的登录与本地存储。

## 高级状态清单

若需捕获弹窗、表单校验、特定滚动位置或复杂登录后的状态，在“页面来源”中改为“状态清单（高级）”。可以导入 JSON、直接粘贴或载入 multi-app-admin 示例。现有清单格式保持兼容。

自动发现覆盖的是可识别的页面入口，不能证明穷举了产品的全部权限、输入组合或运行时错误状态。

## 多页预览（v0.5.1）

捕获完成后，桌面工作台右侧显示“1 / N 页”。用“上一页 / 下一页”或页面下拉列表查看每页；左侧页面列表的“预览”按钮也可以跳转。预览切换不会改变需要导入的页面勾选。

每张预览对应实际捕获成功的页面；失败页不占用预览序号。快速切换会取消旧图片加载，加载失败可重试，过期时会明确提示重新捕获。截图按需请求，最多缓存最近三页，不会一次下载 200 张图片。

旧版本只有第一张截图，升级后请重新捕获。截图仅随当前助手会话保存，退出助手或任务超过最近两个后会清理；导出的 `.h2f.json` 保存图层数据，不包含这组临时预览。Figma 内的紧凑插件仍以页面列表和导入为主，截图浏览位于桌面工作台。
