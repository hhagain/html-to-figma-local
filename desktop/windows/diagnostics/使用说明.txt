Windows 助手 v0.8.0 启动诊断

1. 先从助手的托盘菜单选择“退出捕获助手”，不要只点窗口右上角 X。
2. 完整解压本工具。
3. 双击“启动诊断.cmd”。默认安装位置会自动识别。
4. 若提示未找到助手，将 diagnose.cjs 和 启动诊断.cmd 放到助手 EXE 所在目录，或把 HTML to Figma Capture.exe 拖到 CMD 上。
5. 诊断完成后，把同目录生成的 H2F-Windows-startup-*.json 报告发给开发者。

不需要管理员权限、Node.js 或 npm。工具会检查包内文件、本机端口和应用数据目录写入，并短暂启动后台服务后关闭。报告会隐藏用户目录与会话 token，不会捕获或上传网页，也不会清理已有数据。若启动诊断本身被安全软件阻止，请记录拦截提示。
